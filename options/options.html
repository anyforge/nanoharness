NanoHarness 设置
常规
Token 用量

所有模型的历史 token 用量（输入 / 输出）。

token 用量按每次模型调用累计：优先采用服务商返回的 usage 字段（精确）；若服务商不返回 usage，则按「中文≈1 token/字、其他≈4 字符/token」估算。
大模型

配置大模型 API。支持 OpenAI 兼容与 Anthropic 两种协议。

OpenAI 兼容适用于 DeepSeek / OpenAI / Moonshot 等；Anthropic 适用于 Claude。

常用配置

常用智能体配置

上下文压缩

长对话自动摘要，防止上下文超限。默认参照 Hermes（阈值 0.5、目标 0.2）。

对话占用超过阈值时自动压缩历史，长任务不丢上下文。

模型的上下文长度，用于计算触发阈值。默认 128000。

占用超过此比例即触发压缩。默认 0.5，越小压缩越频繁。

压缩后的目标占用比例。默认 0.2。

录制操作归纳成技能时的单次请求超时，默认 300 秒（5 分钟）。

技能

增删改查技能；技能正文会被 agent 通过 skill 工具按需加载。

MCP 服务器

连接远程 MCP server（HTTP/SSE transport；纯扩展无法使用本地 stdio）。

MCP 暴露

把 NanoHarness 自身作为 MCP server 暴露给其他智能体（Claude / Cursor / 其他 agent）调用。纯扩展无法监听端口，需配合一个 relay 进程（见项目 mcp-relay/）。

可选。设置后，连接需携带此 token 鉴权。

连接地址

          
复制后粘贴到 Claude Desktop / Cursor 的 mcpServers 配置里。远程连接时，把 localhost 换成运行 relay 那台机器的 IP 或域名。
